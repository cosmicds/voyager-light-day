# Voyager Reaches 1 light day from the Earth

On November 18, 2026, 5:16AM EST the Voyager 1 spacecraft will be 1 light day away from the Earth ([JPL](https://science.nasa.gov/mission/voyager/voyager-1/voyager-1-what-is-a-light-day/)). This CosmicDS _Spark!_ celebrates this milestone by taking the viewer on the Voyager mission's journey of discovery. 

## To Build and Run localy
Run
```bash
# make sure you have node installed, and corepack is enabled
yarn install
yarn dev # you will see a message with the local URL to open in your browser
```
